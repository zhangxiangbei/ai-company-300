# AI Company 300

AI公司300强是张向北AI进化论的长期研究项目。

它不是投资榜单、融资排行或估值榜，而是一张观察 AI 时代产业权力迁移的研究地图。这个项目通过持续整理全球重要 AI 公司、AI 产品、AI 赛道和商业模式，帮助普通人理解 AI 产业正在如何变化。
